## About

Great Fits Labels is a landing page for an online second-hand store in Nairobi.
Visitors can read about the store, browse products and find answers to common
questions. I built it to practise semantic HTML and CSS layout.

## Built with

- HTML5 (semantic elements, ARIA labels)
- CSS3 (Flexbox, Grid, custom properties, transitions, media queries)

## Getting started

### Requirements

- A modern browser (Chrome, Firefox, Safari or Edge)

git clone https://github.com/wambua7/TechGadget-Price.git
cd TechGadget-Price
code .
